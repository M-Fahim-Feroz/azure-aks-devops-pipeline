## [1.0.0] - Initial Release
### Added
- End-to-end DevOps pipeline showcasing Azure AKS, Terraform, and GitHub Actions.
- Dockerized FastAPI backend pushed dynamically to Azure Container Registry (ACR).
- Helm-based automated deployment via Ansible.
- Kube-Prometheus stack setup for comprehensive Grafana observability.
- Fully automated CI/CD pipeline bridging infrastructure provisioning to application deployment.
